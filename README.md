**Персональний помічник (Адресна книга)**

Консольний асистент на Python для роботи з контактами: додавання, оновлення, пошук і видалення записів, валідація полів та збереження даних у CSV.

Вимоги та запуск
Python 3.10+ (використовуються лише стандартні бібліотеки: csv, datetime, pathlib, re).

Запуск програми з кореневої папки проєкту:
python main.py

Правила валідації полів:

Ім'я (Name) — обов'язковий непорожній рядок.

Телефон (Phone) — один номер на контакт; рівно 10 цифр (0-9).

День народження (Birthday) — формат DD.MM.YYYY (наприклад, 15.05.1995).

Email (Email) — перевірка стандартного формату user@domain.tld.

Адреса (Address) — непорожній рядок (підтримує пробіли та коми).

Команда,Формат,Опис
hello,hello,Привітання та перевірка роботи бота
add,add <ім'я> [телефон],Додає новий контакт або оновлює телефон існуючого
change,change <ім'я> <новий_телефон>,Змінює номер телефону контакту
phone,phone <ім'я>,Виводить номер телефону контакту
add-birthday,add-birthday <ім'я> <DD.MM.YYYY>,Додає або оновлює дату народження
show-birthday,show-birthday <ім'я>,Виводить дату народження контакту
add-email,add-email <ім'я> <email>,Додає або оновлює email контакту
show-email,show-email <ім'я>,Виводить email контакту
add-address,add-address <ім'я> <адреса>,Додає або оновлює адресу контакту
show-address,show-address <ім'я>,Виводить адресу контакту
find,find <ім'я>,Знаходить контакт за іменем
delete,delete <ім'я>,Видаляє контакт за іменем
all,all,Виводить усі контакти з адресної книги
exit / close,exit або close,Зберігає адресну книгу у CSV та завершує роботу
