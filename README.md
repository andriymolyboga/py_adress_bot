**Персональний помічник (Адресна книга)**

Консольний асистент на Python для роботи з контактами: додавання, оновлення, пошук і видалення записів, валідація полів та збереження даних у CSV.

**Вимоги та запуск**
Python 3.10+ (використовуються лише стандартні бібліотеки: csv, datetime, pathlib, re).

Запуск програми з кореневої папки проєкту:
python main.py

**Правила валідації полів:**

Ім'я (Name) — обов'язковий непорожній рядок.

Телефон (Phone) — один номер на контакт; рівно 10 цифр (0-9).

День народження (Birthday) — формат DD.MM.YYYY (наприклад, 15.05.1995).

Email (Email) — перевірка стандартного формату user@domain.tld.

Адреса (Address) — непорожній рядок (підтримує пробіли та коми).

**Команди:**

hello Привітання та перевірка роботи бота

add <ім'я> [телефон] Додає новий контакт або оновлює телефон існуючого

change,change <ім'я> <новий_телефон>,Змінює номер телефону контакту

phone <ім'я> Виводить номер телефону контакту

add-birthday <ім'я> <DD.MM.YYYY> Додає або оновлює дату народження

show-birthday <ім'я> Виводить дату народження контакту

add-email <ім'я> <email> Додає або оновлює email контакту

show-email <ім'я> Виводить email контакту

add-address <ім'я> <адреса> Додає або оновлює адресу контакту

show-address <ім'я> Виводить адресу контакту

find <ім'я> Знаходить контакт за іменем

delete <ім'я> Видаляє контакт за іменем

all Виводить усі контакти з адресної книги

exit або close Зберігає адресну книгу у CSV та завершує роботу
