# Personal Assistant — Персональний помічник

Консольний застосунок на Python для керування контактами та нотатками. Підтримує пошук, редагування, видалення записів, валідацію даних, роботу з тегами, автодоповнення команд та збереження даних між сеансами роботи.

## Встановлення та запуск

**Вимоги:** Python 3.10+ (протестовано на Python 3.12).

1. Клонуйте репозиторій:

```bash
git clone https://github.com/andriymolyboga/py_adress_bot.git
cd py_adress_bot
```

2. Створіть віртуальне середовище:

```bash
python -m venv .venv
```

Активуйте його:

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
```

3. Встановіть залежності (Rich та Questionary):

```bash
pip install -r requirements.txt
```

4. Запустіть застосунок:

```bash
python main.py
```

## Використання

У головному меню оберіть **Contacts**, **Notes** або **Exit** за допомогою клавіш зі стрілками та Enter.

Після виконання операції наступну команду можна ввести з клавіатури. Необхідні параметри застосунок запитує окремо.

### Команди для контактів

| Команда | Опис |
|---|---|
| `add` | Додати контакт або оновити його телефон |
| `all` | Переглянути всі контакти |
| `find` | Знайти контакт за іменем |
| `change` | Змінити номер телефону |
| `phone` | Переглянути номер телефону |
| `add-birthday` | Додати або оновити дату народження |
| `show-birthday` | Переглянути дату народження |
| `birthdays` | Переглянути майбутні дні народження за задану кількість днів (0–3650) |
| `add-email` | Додати або оновити email |
| `show-email` | Переглянути email |
| `add-address` | Додати або оновити адресу |
| `show-address` | Переглянути адресу |
| `delete` | Видалити контакт |

**Правила валідації:**

- Ім'я — обов'язковий непорожній рядок.
- Телефон — рівно 10 цифр, один номер на контакт.
- День народження — коректна дата у форматі DD.MM.YYYY.
- Email — формат user@domain.tld.
- Адреса — непорожній рядок, підтримує пробіли та коми.

Під час створення контакту обов'язковим є лише ім'я. Пошук здійснюється за повним іменем без урахування регістру.

### Команди для нотаток

| Команда | Опис |
|---|---|
| `add` | Створити нотатку |
| `all` | Переглянути всі нотатки |
| `find` | Знайти нотатку за ID |
| `search` | Знайти нотатки за назвою або текстом |
| `edit` | Редагувати нотатку |
| `delete` | Видалити нотатку |
| `delete-all` | Видалити всі нотатки після підтвердження |
| `add-tag` | Додати тег |
| `search-tag` | Знайти нотатки за тегом |
| `sort-tags` | Сортувати нотатки за тегами |

Назва та текст нотатки є обов'язковими. Теги необов'язкові, зберігаються без дублікатів та без урахування регістру.

### Загальні команди

| Команда | Опис |
|---|---|
| `menu` | Показати меню поточного розділу |
| `back` | Повернутися до головного меню |
| `exit` | Зберегти дані та завершити роботу |

Застосунок підтримує автодоповнення команд та пропонує найближчу команду у разі помилки введення, наприклад:

```text
? Enter command: finnd
⚠ Unknown command. Did you mean 'find'?
```

## Зберігання даних

Контакти та нотатки зберігаються у домашній директорії користувача:

```text
~/.personal_assistant/
├── addressbook.csv
└── notes.csv
```

Дані автоматично завантажуються під час запуску та зберігаються під час коректного завершення роботи.

## Демонстраційні дані

Папка `demo_data/` містить приклади контактів та нотаток.

Для їх використання скопіюйте CSV-файли до директорії `~/.personal_assistant/` перед запуском застосунку.

macOS / Linux:

```bash
mkdir -p ~/.personal_assistant
cp -n demo_data/*.csv ~/.personal_assistant/
```

Наявні файли не перезаписуються. Перед заміною власних даних створіть резервні копії.
